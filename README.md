# KuroKishi India — studio website

A single-file static site (`index.html`). No build step.

## Put it on GitHub
1. Create a new repository on github.com (for example `kurokishi-india`).
2. Click **Add file → Upload files**, drag in `index.html` and `README.md`, then **Commit changes**.

## Make it live with Vercel
1. Sign in at vercel.com with your GitHub account.
2. **Add New → Project**, choose the repository, leave every setting as it is, and press **Deploy**.
3. Vercel gives you a live link. Later edits to `index.html` on GitHub redeploy automatically.

## Audition form → your email
Applications are sent to kurokishiinc@gmail.com through FormSubmit.
The first time anyone submits the form on the live site, FormSubmit emails you an activation link. Click it once (check Spam or Promotions if you can’t find it), and every application after that arrives in your inbox. The email address changed, so this activation is needed again.
Test the form on the live Vercel link, not inside Claude.

## Visitor shortcuts
- **Free scroll** is always on: text and numbers show instantly, the page is shorter, and there is no glide or auto-playing ending. A "Play the final scene" button at the bottom plays the cinematic ending on request.
- The floating **Audition** button jumps to the form. Its small arrow tucks it to the side of the screen, where a **JOIN** tab brings it back.
